What is the difference between a Preemptive and Non-Preemptive Kernel, and why does Preemption prevent priority inversion with priority inheritance?

lightbulb

Verified by AI Tutor

Non-preemptive: Does not allow a process running in kernel mode to be interrupted until it exits kernel mode or blocks.

Preemptive: Allows preemption even in kernel mode, ensuring real-time responsiveness for high-priority tasks.

Priority Inheritance: Dynamically elevates the low-priority thread holding a critical resource to the priority of the highest awaiting task.
